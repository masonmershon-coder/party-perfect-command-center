# Hiring outreach — 1–5 apps/day

**Goal:** 1–5 solid applications per Tulsa day on [partyperfectjobs.com](https://partyperfectjobs.com).  
**Policy:** Always hiring **all** roles; ads can lead with tents/delivery (physical filter) but CTA is the full form.  
**Track:** Command Center → Hiring → **Today vs goal**.

Every ad CTA = **https://partyperfectjobs.com** only (Indeed **Easy Apply OFF**).
